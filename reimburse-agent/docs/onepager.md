# 一页纸方案：报销审核 AI 同事

## 一句话

财务共享中心每天要审几百张差旅餐饮报销单：抄发票字段、查验真伪、查企业状态、查重复报销、对制度条款。
这些活儿规则明确但极耗人力。我们让它变成一位 AI 同事的日常：**它做核查和初判，人只处理真正需要判断的单据。**

## 场景与价值

| 现在 | 用之后 |
| --- | --- |
| 一张单平均 5–8 分钟：看票、查票、翻制度、填意见<br>（**待验证假设**，无实测来源） | 秒级给出初判与依据（实测 8.5 秒/单），人只复核被标红的 |
| 判定标准靠人记条款，同一个人不同时间可能判不一样 | 26 个判定项全部由规则代码判定，同一条款永远同一结果 |
| 查验失败时，人往往"看着没问题就过了" | 无法核验的单据一律不进自动通过，强制转人工 |
| 复核结论散落在邮件里 | 复核结论写回查重库，直接影响下一张单据 |

可量化的成功标准：在 60 条带标准答案的测试集上，结论与核准金额 100% 一致；
每条单据给出 15 条规则中实际适用的每一条的"命中/不命中/不作判定"及理由。

## 怎么工作

1. **看票**：DeepSeek 与 Claude 各自独立把发票抄成结构化字段，带置信度。
2. **比对**：逐字段比对。不一致、置信度低于 0.8、读不出来 → 该字段作废，不猜。
3. **核验**：通过 MCP 工具查发票真伪状态、查销售方企业状态、查历史重复报销。只读，可注入故障。
4. **判定**：15 条规则 / 26 个判定项，全部由代码判定；结论取最严格者。
5. **出意见**：默认由规则结果拼接（金额与条款不经模型）；可选模型润色，但生成后回查金额与条款编号。

## 责任边界：它能做什么、不能做什么

**能**：抽字段、查外部事实、按制度判初判、写审核意见、标记"未核验/未判定"。
**不能**：付款、改凭证、冲销发票、替人做最终决定、在无法核验时放行。

设计上把"不确定"显式化：字段不可信 → 判定项跳过并写明原因；工具失败或超时 → 相关判定项不作判定。
这些情况下结论只会是"转人工复核"，不会是"通过"。

## 权限与数据安全

- 三个 MCP 工具全部只读，没有任何写操作。
- 工具按最少条件查询（发票号、税号、申请人），不整库返回；历史记录超 200 条截断。
- 服务默认只监听本机；跨机访问强制要求 Bearer 令牌，没配令牌直接拒绝启动。
- 令牌只从环境变量或受限权限文件读取，不进命令行、不进日志；日志只记令牌名与指纹。
- 审计日志记调用方、来源 IP、方法、状态码、耗时，不记业务数据。
- 模型密钥只从环境变量读；配置文件出现密钥字段直接拒绝启动；界面只显示"已配置/未配置"。

## 成本

单张单据：抽取两次（两家模型各一次）+ 可选一次润色。

| 口径 | 金额 | 来源 |
| --- | --- | --- |
| **实测（真实模型，60 条平均）** | **$0.0101/单** | `docs/eval-real.md` |
| 其中 Claude 占比 | 约 90% | 同上 |
| 早期估算（合成模式，无真实调用） | $0.002–0.004/单 | 按列表价推算，**已作废，仅留作对照** |

界面每次审核都显示估算成本。工具查询为本地 mock，不产生费用。

## 人机协作

- 人被叫来的只有三类：字段不可信、外部事实无法核验、规则要求人工确认（如席别特批编号真伪）。
- 人处理完的结论直接写回查重库，下一次遇到同一张发票会被判为重复报销——这是"记忆"。
- 人也可以在任意结论上覆盖 AI 的初判，覆盖记录留痕。

## 容错

| 故障 | 系统行为 |
| --- | --- |
| 一个模型超时/不可用 | 另一模型继续，但关键字段无交叉校验 → 转人工 |
| 两个模型都不可用 | 不调工具、不判定，直接转人工 |
| 查验工具超时 | 视为状态未知，相关判定项不作判定，转人工（不当"查无此票"） |
| 工具返回乱码 | 判为失败，不解析成空结果 |
| 发票某字段污损 | 该字段作废，依赖它的判定项跳过 |
| 模型润色时改了金额 | 机器核对不通过，丢弃模型文本，用规则拼接稿 |

## 试用路径

1. 本机一条命令起界面（无密钥也能演示）；
2. 用 60 条测试集逐条试，每条都有标准答案可对照；
3. 现场可开关模型、注入工具故障，验证降级路径；
4. 接入真实数据只需替换工具后端（`DataSource` 接口已定）。

## 可复现

- 测试集同种子生成，文件哈希稳定；规则表和生成器读同一份 `rules.json`。
- 规则引擎与标准答案由两条独立代码路径推出，在 60 条用例上完全一致，这条断言固化在测试里。
- 每次审核记录模型、开关、故障注入参数与全部事件，可逐步回放。
